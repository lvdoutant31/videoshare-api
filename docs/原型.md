# 映流短视频系统产品原型设计说明

## 1. 设计目标

本原型用于验证《短视频管理与播放系统 PRD》V1.1 的关键业务闭环：后台完成本地视频上传、审核、发布与治理；用户在手机端完成企微/手机号登录、沉浸式播放、点赞、收藏、评论、关注，以及微信、企微和站内用户转发。

本版原型品牌名使用“映流”。旧探索页中的“抖音”品牌字样与完整“私信”概念不进入正式原型；站内社交只保留不可回复的视频分享收件箱。

## 2. 视觉方向：A「暗场影像 + 明场运营」

- 手机端采用暗色沉浸式舞台，让视频成为主要光源；后台采用浅色高密度工作界面，强调状态、效率和可审计性。
- 品牌色：墨黑 `#0B0D12`、石墨 `#1F2937`、云白 `#F6F8FB`、流光青 `#20D9D2`、互动珊瑚 `#FF5A62`、操作靛蓝 `#5B6CFF`。
- 中文字体使用 Noto Sans SC；数字、英文与指标使用 Inter。标题克制使用粗字重，正文优先可读性。
- 标志性元素为“流光进度线”：青色主线叠加短珊瑚光点，贯穿手机播放进度、后台任务进度和关键状态提示。
- 所有圆角、阴影和装饰服从信息层级；手机操作区以半透明暗色承载，后台卡片以细边框和轻阴影承载。

## 3. 画板与屏幕范围

### 手机端（自适应）

1. `M01 登录`：企微快捷登录优先，手机号登录为降级入口，展示协议确认。
2. `M02 推荐流`：单视频全屏、作者与标题、点赞/评论/收藏/转发、流光进度线、底部导航。
3. `M03 评论面板`：底部抽屉、热度/最新排序、两级回复、评论输入与发送。
4. `M04 分享渠道`：微信、企微、站内用户、复制链接四个固定入口，并说明渠道降级。
5. `M05 选择站内用户`：搜索、最近联系人、多选、20 人上限、逐项发送结果。
6. `M06 分享收件箱`：不可回复的视频卡片、发送人、发送时间、内容失效状态。
7. `M07 作者主页`：作者资料、关注状态、统计数字与公开视频网格。
8. `M08 个人中心`：收藏、点赞、历史、关注、账号设置与企微绑定状态。

### PC 后台（自适应）

1. `A01 企微扫码登录`：企微二维码、账号密码降级入口、会话安全提示。
2. `A02 运营工作台`：核心指标、趋势、审核/举报待办、本地存储状态。
3. `A03 视频列表`：筛选、表格、状态、批量上下架、转码失败重试。
4. `A04 本地上传与编辑`：分片上传、完整性校验、转码进度、封面和发布信息。
5. `A05 视频审核`：视频预览、风险信息、历史记录、通过/驳回/要求修改。
6. `A06 用户管理`：账号、企微绑定、状态、违规次数、禁言与封禁操作。
7. `A07 评论与举报`：上下文、风险标记、隐藏/恢复/删除和处置记录。
8. `A08 系统与存储`：本地媒体目录、磁盘容量、备份、企微参数与告警阈值。

## 4. 关键交互流程

### 手机观看与互动

`进入推荐流 → 当前视频自动播放 → 上滑切换 → 点赞/收藏乐观反馈 → 打开评论时暂停 → 关闭后恢复原播放状态`

分享流程为 `点击转发 → 选择微信/企微/站内用户/复制链接`。站内用户继续进入接收人选择页；发送后写入分享收件箱。外部渠道不展示虚假的“送达成功”，普通浏览器不支持指定渠道时降级为系统分享或复制链接。

### 后台内容生命周期

`本地分片上传 → 文件校验 → 转码与封面 → 填写资料 → 提交审核 → 审核通过 → 发布 → 推荐分发 → 下架/删除`

上传过程中明确区分“正在上传、校验中、转码中、转码失败、待审核”等状态。磁盘达到 90% 时禁用新上传入口，但保留已有视频播放和后台处置能力。

### 企微登录

手机端在企微环境优先展示快捷授权；PC 后台展示扫码登录。首次授权创建账号或在手机号验证后绑定既有账号；绑定冲突进入明确错误态，不自动合并。

## 5. 组件策略

- 手机端复用：顶部栏、视频动作按钮、用户头像、底部导航、评论行、分享渠道项、用户选择项、视频卡片。
- 后台复用：侧边导航、页面标题栏、指标卡、筛选项、主次按钮、状态标签、数据表格、进度条、告警条、确认对话框。
- 图标优先使用 Material 3；后台基础控件优先参考 Simple Design System。品牌级组件单独建立本地组件，不复制远程组件为新主组件。
- 所有重复元素必须使用组件或实例；原型屏幕不保留无意义的重复手工图层。

## 6. 内容与状态样例

- 视频样例使用企业知识、产品培训和团队文化内容，避免娱乐化占位文案与真实抖音品牌元素。
- 工作台展示：今日播放 128,460、待审核 18、播放失败率 0.7%、本地存储使用率 72%。
- 状态至少覆盖：已发布、待审核、转码中、转码失败、已下架；用户覆盖正常、禁言、临时封禁；分享卡片覆盖可播放与已失效。
- 错误提示直接说明解决路径，例如“磁盘空间不足，已暂停新上传；清理或扩容后重试”。

## 7. 原型验收标准

- 16 个核心画板全部存在，命名、尺寸和层级清晰，手机与后台视觉语言统一但场景有明确区分。
- 视频播放、评论、四类分享、站内用户选择、分享收件箱、企微登录、本地上传和存储告警均有可评审界面。
- 不出现完整私信、群聊、云对象存储或创作者投稿等超出 V1 的功能。
- 中文文本无缺字；触控目标、对比度、表格密度和关键错误态具备基本可用性。
- 变量、文字样式、效果样式和复用组件可被后续研发标注与扩展；画板无重叠、裁切、溢出和明显占位内容。
