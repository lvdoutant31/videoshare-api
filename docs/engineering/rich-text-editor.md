# 富文本编辑器

B、C 端统一采用 Tiptap 3，正文仍通过 `description` 保存 HTML，不需要额外迁移历史数据。

- B 端新增和编辑内容支持标题层级、字体、字号、文字颜色、加粗、斜体、下划线、列表、对齐、链接、表格和撤销重做。
- C 端发布使用适合手机的简化工具栏，保留相同正文格式解析能力。
- 图片可多选上传，也可粘贴或拖入编辑器；上传复用已有图片 API 和 MediaStorage 的本地／OSS 实现。按选取顺序插入光标位置，正文第一张图片仍作为图文封面。
- 正文 HTML 在前后端经过白名单清洗，保留文字样式与表格合并单元格，删除脚本、事件处理属性和不安全链接／CSS。
- 详情、审核与视频正文阅读区域统一保留列表、标题、表格及链接样式。

验证覆盖编辑器格式重新载入、多图顺序、撤销重做、后端清洗及移动端发布流程。
