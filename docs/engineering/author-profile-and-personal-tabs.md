# 作者搜索、主页与个人内容 Tab

## 页面行为

- 首页搜索支持“内容 / 作者”，作者按昵称或 videoshare 号搜索，点击进入作者主页。搜索关键词最多 60 字。
- 他人主页显示“作品 / 喜欢”，移除原来的私密占位。作品统计包含公开发布的视频和图文；喜欢查询主页作者的点赞记录，只展示当前公开可见的内容。
- “我的”显示资料、统计、设置按钮以及“作品 / 收藏 / 喜欢 / 历史”四个 Tab。收藏和历史仍只能通过当前登录用户接口读取。
- 个人页作品和“我的内容”直接分页展示本人全部状态的作品，不提供状态下拉框；审核中、需修改、已下架等状态显示在卡片上。点击自己的作品进入现有内容详情，保留编辑、重新提交审核和撤下能力。
- 编辑资料、关注、粉丝、消息、协议和账号操作集中于设置。历史 Tab 保留清空操作和观看时间。
- 列表支持滚动续加载、手动加载更多和失败重试。各 Tab 独立保留数据及滚动位置；离开路由前保存位置，详情返回后恢复。重新显示已加载的 Tab 时，保留旧内容并刷新已加载的分页范围，反映新增作品、点赞、收藏和历史以及撤下、取消操作。
- 缓存按作者 ID、个人账号 ID 和页面类型区分；缓存页面暂停播放。个人作品封面顶部标记“视频 / 图文”，底部左侧为点赞数、右侧为播放量；旧后端未提供统计时显示“—”。

## 接口

| 接口 | 返回及权限 |
| --- | --- |
| `GET /api/v1/app/users?keyword=&cursor=&limit=20` | 游标分页作者列表，包含字符串 ID、昵称、头像、公开作品总数和访问者的关注状态；仅正常、未删除账号 |
| `GET /api/v1/app/users/{id}` | 原公开资料增加 `worksCount` |
| `GET /api/v1/app/users/{id}/videos` | 原作品游标分页；查询与总数复用现有公开可见条件 |
| `GET /api/v1/app/users/{id}/likes` | 查询该作者点赞记录；卡片互动状态按当前访问者计算 |
| `GET /api/v1/app/me/content/page?status=ALL&cursor=&limit=20` | 登录用户自己的分页内容，返回 `items / nextCursor / total`；C 端固定读取全部状态，总数为本人作品总数 |

个人分页 `status` 支持 `ALL / PUBLISHED / REVIEW / REVISION / OFF_SHELF / UNPUBLISHED`。每页 1–50 条，作品按 ID 倒序，以字符串 ID 为游标。旧 `GET /me/content` 为兼容旧客户端保留；新页面使用分页接口，不再受旧接口 100 条限制。

作者作品总数、作品列表、收藏和点赞列表使用同一公开条件：审核通过、已发布、公开、未删除、未下架、作者正常，视频原始媒体可用；无视频的图文同样可见。不自动改变既有内容可见性，不删除私密数据，不修改数据库结构。

## 发布与验证

新增测试覆盖大 ID、真实总数、公开可见条件、作者与访问者身份区别、分页与筛选、旧请求丢弃、空中间页、返回位置、撤下和取消点赞后的刷新、设置资料编辑、手机和桌面布局，以及举报回归。

使用 `deploy/build-release.ps1` 同时构建 B / C / 后端并准备 Windows 服务发布 ZIP。安装按 `deploy/README.md` 执行，保留现有配置、数据库和媒体；本次没有新增数据库迁移。

## 本地运行版本核对

本地 Docker 的前端目录直接挂载 `yingliu-c/dist`，重新构建前端即会更新页面；后端 JAR 位于镜像内，必须单独重建并更新 `app` 服务。只更新前端时，新接口可能返回 404。

2026-10-13 经用户明确授权，仅更新本地 Docker 测试后端；服务器继续使用 Windows BAT 部署。更新前已备份当前数据库，保留旧镜像，并确认运行配置和原媒体挂载一致。升级后的内容、用户、媒体记录数与备份前相同。

诊断时先直接请求 `8080/api/v1/app/me/content/page`，再检查 `5173/videoshare/api/v1/app/me/content/page`。接口存在时，未登录返回 401；两个地址都返回 404 表示需要核对后端版本。当前本地接口已恢复，作者搜索返回 200。

## 个人页交互与可读性优化

“我的”页面沿用白底蓝色风格，增加带文字的设置入口、个人统计分组和作品数量徽标。
按用户要求移除作品状态下拉框及其占用行，作品列表直接接在 Tab 下方。Tab 支持左右方向键、Home/End 和单一键盘停靠点，
并通过 `aria-controls` / `aria-labelledby` 关联各自面板。点击或键盘切换均保留各 Tab 的滚动位置。
标题采用两行平衡换行，封面统计加深底部遮罩；窄屏未发布作品用类型图标避免和状态标记重叠。
对比度、焦点轮廓、点按反馈和减少动态效果均使用个人页的统一样式变量。
本轮只修改 C 端页面和样式，服务器已有上一版统计后端时可仅替换 H5 静态资源。

## 作品统计接口

自己的作品列表、分页列表和详情现在返回 `likeCount` 与 `playCount`。
点赞数沿用公开内容的 `user_video_like` 实际记录计数；播放量取 `video_stats.play_count`。
只对当前用户查询结果中的作品 ID 批量读取统计，空页不发统计查询，缺少统计记录时返回 0。
不新增数据库迁移。客户端在封面左下角显示点赞数、右下角显示播放量，视频和图文均保留类型标记。
较旧后端没有这些字段时显示“—”，避免把未提供的数据显示为零。
