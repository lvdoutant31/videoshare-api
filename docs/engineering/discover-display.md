# 首页展示：同页搜索

首页继续使用 `/discover`。默认显示搜索框、分类/标签、热门封面卡片和折叠的内容概览。
手机与桌面均默认折叠概览；点击展开不重新请求接口。

提交关键词、点击分类/标签或切换作者搜索后，在同页展示结果，隐藏热门和内容概览。
内容搜索以横向列表显示完整标题、作者、分类、标签、播放量和发布时间。
热门与结果封面均标识图文或视频时长；视频时长未知时显示“视频”。
视频进入既有播放页，图文进入既有详情页。

## 清除与恢复

| 操作 | 结果 |
| --- | --- |
| 搜索框“清空关键词”或移除关键词标签 | 清空关键词，保留分类、标签、搜索类型与排序；停留在结果状态 |
| “清除筛选”或空结果中的“清除筛选条件” | 清空分类/标签，保留关键词和排序 |
| “返回首页” | 清空全部搜索条件，恢复内容搜索及综合排序，显示热门并折叠概览 |
| 空结果中的“修改关键词” | 滚动至搜索框，聚焦并选中已有关键词；修改后提交才重新查询 |

首次加载和新结果加载显示骨架屏，查询完成前不显示空结果提示。
查询失败保留条件并提供重试。刷新与加载更多沿用已有结果/分页逻辑。
搜索条件与排序保存在 URL；从详情返回保留结果、已加载页和滚动位置。
仅在首页输入尚未提交的文字再清空时，不触发搜索请求。

## 验证与发布

单元测试覆盖清除操作的不同语义、内容类型/作者展示、加载骨架和空结果聚焦。
手机和桌面浏览器验证概览默认折叠、长标题不截断、同页切换、筛选保留、详情返回及无横向溢出。
排序仍使用 [热门与搜索排序规则](discover-ranking.md)，本轮没有修改后端接口或数据库结构。
发布使用 `deploy/build-release.ps1` 构建 B/C 前端和后端，生成 Windows 服务发布包。
