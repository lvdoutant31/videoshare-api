# 分类管理导航名称修复设计

## 问题

`/admin/system/categories` 页面用于分类管理，但侧栏中 `/system/categories` 对应入口显示为“系统与存储”，造成页面语义与导航名称不一致。

## 方案

- 将 `/system/categories` 导航项名称改为“分类管理”。
- 保留现有 `Setting` 图标和 `/system/categories` 路由。
- 保留独立的“标签管理”入口及 `/system/tags` 路由。
- 不增加父级菜单、不合并分类与标签页面、不调整其他导航项。

## 激活规则

- 访问 `/admin/system/categories` 时，仅“分类管理”显示当前页状态。
- 访问 `/admin/system/tags` 时，仅“标签管理”显示当前页状态。

## 验证

- 添加侧栏测试，模拟分类路由并断言当前项文本为“分类管理”。
- 运行前端完整测试、类型检查和生产构建。
- 在浏览器重新加载分类页，检查侧栏名称、高亮状态、控制台错误和页面截图。
